# CIRCUIT ...with the edge 👗⚡
### Lagos, Nigeria • Powered by Solana

**Circuit** is a made-to-order fashion protocol that eliminates the fashion industry's $500B unsold inventory crisis by ensuring no garment is manufactured until it is confirmed by a buyer on-chain.

## 🌟 The Vision
> "Where physical rarity meets on-chain truth."

Traditional fashion relies on guessing demand. **Circuit** flips the script:
1. **Demand First**: Production begins only after 100% pre-order confirmation via Solana Trustless Escrow.
2. **Provenance Built-In**: Every garment features an embedded NFC chip cryptographically linked to a Solana NFT (Digital Product Passport).
3. **Perpetual Value**: A 7% royalty is automatically enforced on every secondary market resale, creating a compounding revenue stream for designers.

## 🛠️ The MVP Dashboard (Hackathon Demo)
The included dashboard is a high-fidelity demonstration of the Circuit Operational Protocol. It simulates the real-time "Verification Maze" used to scale Drop Zero.

### Key Demo Features:
- **Live Provenance Feed**: Watch in real-time as physical sales are "minted" and "verified" on the Solana blockchain.
- **Secondary Royalty Engine**: Once Drop Zero (40 units) is sold out, the dashboard demonstrates the secondary market resale engine, showing how 7% royalties compound automatically.
- **Digital Product Passport (DPP)**: Inspect individual garments to see their unique Solana Mint Address, NFC UID, and production provenance.
- **World-Class UI**: A "Luxury Tech" aesthetic designed for the modern Lagos fashion scene, fully responsive on all devices.

## 🚀 Technical Stack
- **Frontend**: HTML5, CSS3 (Custom Design System), Vanilla JS.
- **Blockchain (Architecture)**: Solana (Metaplex Programmable NFTs).
- **Hardware**: NFC NTAG213/215 Protocol.
- **Payment**: Paystack (MVP) transitioning to Solana Escrow.
